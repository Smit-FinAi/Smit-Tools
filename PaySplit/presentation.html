Problem Statement

Splitting Payments
Is Unnecessarily Hard

In everyday life — from splitting bills at restaurants to dividing freelance invoices across milestones — people struggle to collect money via UPI without overpaying, underpaying, or manually tracking everything.

😤
No Easy Split Tool
UPI apps only support single-recipient QR codes. There is no native way to request payment in multiple portions from one screen.
🔢
Floating-Point Errors
Dividing ₹100 by 3 gives ₹33.333…, causing ₹0.01 discrepancies when totalled. Manual calculation leads to rounding mistakes.
🕐
Time-Consuming
Merchants and freelancers have to generate QR codes one at a time across multiple apps, wasting precious time and causing friction.
📵
No Offline Access
Most payment tools require an active internet connection and a backend server, making them inaccessible in low-connectivity zones.

Tech Solution

PaySplit — A Zero-Backend
UPI QR Generator PWA

A fully client-side Progressive Web App built with vanilla HTML5, CSS3 & JavaScript — no server, no signup, no data stored externally. Runs in a browser and installs on your phone like a native app.

🏗️
Tech Stack
HTML5 CSS3 Vanilla JS QRCode.js JSZip PWA Service Worker GitHub Pages
🧮
Integer Paise Arithmetic
All calculations use integer paise (1 INR = 100 paise) with Math.round(x * 100). Remainder paise are distributed across the first N splits — sum is always exact.
📲
PWA — Works Offline
Service Worker caches the full app shell. Install on Android/iOS homescreen. Standalone mode, no browser chrome. Zero backend required.
🔗
Standard UPI Deep Link URI
upi://pay?pa=yourname@upi
&pn=Payee Name
&am=333.34
&cu=INR&tn=Description
&tr=PS_TXN_REF_01
Scannable by GPay, PhonePe, Paytm, BHIM, and all UPI apps.
⬇️
Export & Share
Download each QR as PNG, download all as ZIP bundle with TXT summary, Web Share API for mobile, and browser print for physical copies.
03 / 04
How to Use the Tool

Generate Split QR Codes
in 4 Simple Steps

1
Enter Payment Details
Type the total amount in ₹, your UPI ID (e.g. smit@okaxis), payee name, and an optional description. All fields are validated before proceeding.
2
Choose Number of Splits & Mode
Pick 2–20 splits. Use Equal Split for automatic paise-accurate distribution, or Manual to enter each amount yourself with a live balance tracker.
3
Generate QR Codes
Click Generate QR Codes. The dashboard shows total, allocated, and pending amounts. Individual QR cards appear — each with the exact split amount embedded in the UPI URI.
4
Download, Print or Share
Download each QR as PNG, grab all as a ZIP, print the full payment summary, or share via mobile Share API. Payer scans each QR with any UPI app to pay the exact amount.
✅
Input Validations
• Minimum ₹1 — maximum ₹1 crore
• UPI format: name@provider
• Manual split sum must = total
• 2–20 splits enforced
• All fields required before generate
⚠️
Important Note
Scanning a QR code does not confirm payment. Always verify settlement in your UPI app or bank statement. PaySplit only generates QR codes — it does not process or track payments.
📦
Install as App
Open in Chrome / Edge → tap the install banner → use PaySplit offline from your homescreen, just like a native app.
